# Mohib Salon — Premium Men's Grooming

A premium, responsive website concept for a men's grooming salon in Islamabad, Pakistan.

## Features
- Distinctive charcoal, deep olive and brushed-gold visual identity
- Responsive desktop and mobile layouts
- Men's grooming service menu with PKR prices
- Complete grooming package
- Direct WhatsApp appointment links
- Click-to-email contact link
- Mobile navigation and automatically updated footer year
- Semantic HTML and accessible navigation labels

## Run locally
1. Extract the ZIP file.
2. Open the extracted `mohib_salon_premium` folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click in the editor and choose **Open with Live Server**.
5. The website opens in your browser.

## Project files
- `index.html` — page content and contact links
- `style.css` — design, layout and responsive breakpoints
- `script.js` — mobile menu and footer year

## Image and publishing note
The website uses externally hosted Unsplash photography URLs. These are real photographic images rather than AI-generated images, but they are stock photographs and may also appear on other websites. For a genuinely distinctive client presentation, replace them with photographs taken at the actual salon (with permission) or properly licensed images selected for the business. Confirm service prices and all contact details with the business owner before launch.
